# Учебный интернет-магазин

## Описание

Учебный многостраничный сайт интернет-магазина по дисциплине
«Фронтенд и бэкенд разработка».

Проект последовательно развивается в рамках практических работ
и служит основой для контрольной работы №1
«HTML и CSS: разработка многостраничного сайта».

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог с карточками товаров и статическим блоком фильтров;
- `contacts.html` — контактная информация;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и учебная обработка формы;
- `images/` — папка для изображений;
- `.gitignore` — исключения для Git.

## Используемые технологии

- HTML;
- CSS;
- JavaScript для модального окна и проверки формы;
- Git и GitHub.

## Как посмотреть проект

Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages ниже.
Через общее меню можно перейти в каталог и на страницу контактов.

## Реализованные элементы

- семантическая HTML-структура страниц;
- единое меню и якорные ссылки;
- карточки популярных товаров;
- модальное окно с формой заявки;
- проверка обязательных полей, e-mail и телефона;
- состояния `:hover`, `:focus-visible` и `:disabled`;
- CSS-переменные;
- Flexbox для меню и внутренней структуры карточек;
- CSS Grid для карточек и раскладки каталога;
- хлебные крошки на внутренних страницах.

Фильтры каталога пока являются статическим учебным макетом.
Форма не отправляет данные на сервер: после проверки полей
показывается учебное сообщение.
