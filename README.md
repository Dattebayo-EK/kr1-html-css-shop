# ДораТехно

Многостраничный сайт магазина электронной техники. В каталоге представлены смартфоны, наушники и ноутбуки — по три модели в каждой категории.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект выполнен по дисциплине «Фронтенд и бэкенд разработка». В нём есть главная страница, каталог, страницы товаров, форма заявки и контакты. Для оформления используются общий CSS-файл, семантическая HTML-разметка, Flexbox и CSS Grid.

## Страницы проекта

| Страница | Содержание |
| --- | --- |
| `index.html` | Главная: баннер, популярные модели, преимущества и ответы на частые вопросы |
| `catalog.html` | Категории товаров, карточки, статические фильтры и таблицы сравнения |
| `product.html` | Страница ноутбука Vector S14 с описанием, ценой и таблицей характеристик |
| `product-*.html` | Страницы остальных восьми моделей |
| `order.html` | Форма оформления заявки и примеры предыдущих заявок |
| `contacts.html` | Контактная информация и модальное окно обращения по заявке |
| `cart.html` | Пример корзины с тремя товарами и итоговой суммой |
| `delivery.html` | Условия получения, таблица доставки и ответы на вопросы |

## Структура проекта

- `css/style.css` — общие стили страниц и компонентов.
- `js/main.js` — открытие модального окна, проверка форм, выбор товара в заявке и прокрутка каталога вверх без сброса категории.
- `images/` — девять локальных SVG-иллюстраций товаров.
- `.gitignore` — исключения для Git.
- `README.md` — описание проекта.

## Используемые технологии

HTML5, CSS3, JavaScript, Git и GitHub Pages.

## Самостоятельные доработки

- Каталог расширен до девяти моделей с отдельной страницей для каждой.
- Для каждой категории добавлены свои группы фильтров и таблица сравнения товаров.
- Добавлены страницы корзины и доставки, история заявок и раздел частых вопросов.
- Карточки дополнены характеристиками, бейджами и ссылками на оформление заявки.
- Добавлены хлебные крошки, ссылка перехода к содержимому, видимый фокус и кнопка «Наверх».
- Добавлены локальные SVG-иллюстрации и единое оформление страниц.
