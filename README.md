# ДораТехно

Многостраничный сайт магазина электронной техники. Проект создан для контрольной работы №1 по дисциплине «Фронтенд и бэкенд разработка».

## Содержание сайта

В каталоге представлены девять товаров: три смартфона, три модели наушников и три ноутбука. Для каждого товара есть отдельная страница с описанием, ценой, характеристиками и комплектацией. Категории дополнены таблицами сравнения и макетами фильтров.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная страница с баннером, популярными товарами и ответами на вопросы |
| `catalog.html` | Категории, карточки товаров, фильтры и таблицы сравнения |
| `product.html` | MacBook Air 13″ M2 8/256 ГБ |
| `product-*.html` | Страницы остальных восьми товаров |
| `cart.html` | Пример корзины с тремя товарами и итоговой стоимостью |
| `order.html` | Форма заявки и примеры предыдущих заявок |
| `delivery.html` | Способы получения и условия доставки |
| `contacts.html` | Контакты и форма вопроса по заявке в модальном окне |

## Структура проекта

- `css/style.css` — оформление страниц, адаптивная сетка и состояния элементов.
- `js/main.js` — выбор товара в форме, проверка полей, модальное окно и кнопка прокрутки каталога вверх.
- `images/` — локальные фотографии товаров.
- `README.md` — описание проекта и источники изображений.
